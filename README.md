# RE:CARE — 逆流病棟

誤答した疾患の病態をアバターが疑似再現する、看護師国家試験対策ブラウザゲームのプロトタイプです。判断ミスが病気を引き起こす設定ではなく、学習用の病態リンク装置が症状を再現する世界観です。

## 起動

`index.html` をブラウザで開くだけで動作します。ローカルサーバーを使う場合は、このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。

## 現在の内容

- 第115回看護師国家試験をもとにした22問と、独自作成の疾患別演習278問、合計300問を収録
- 循環器、呼吸器、脳・神経、消化器、腎・泌尿器、内分泌・代謝、感染症、血液・免疫、母性・小児、救急・重症の10領域
- 300問のプールからモードに応じてランダム出題
- 世界観、遊び方、前回成績を表示するタイトル画面
- 正誤判定、連続正解、体調・SpO2・脈拍・集中力の変化
- 誤答に対応した状態異常と解説
- 選択肢ごとの独自解説
- 最終スコアと要復習問題の保存（ブラウザの localStorage）
- 選んだ回答と結果を遡って読めるケア記録
- 低酸素、不整脈、関節痛、筋力低下などを視覚化する身体アバター
- 疾患名・症状説明・出題領域から観察部位を判定し、身体図上に所見を表示する症状エンジン
- 脳・気道・肺・心臓・肝臓・胃・腎臓・腸・膀胱・関節を分けた人体模型アバター
- 発症した臓器の異常表示は次の問題にも持続し、回復時のみ古い症状から解除
- ユーザーネームと4桁コードによる端末内ログイン、ユーザー別の成績・XP・習熟度保存
- Supabase接続時は同じユーザーネームと4桁コードで別端末から学習記録を同期
- クラウド同期状態、オフライン時の未送信キュー、接続復帰時の自動再送
- スマートフォン用人体模型ショートカット、キーボードフォーカスと読み上げ支援
- 独自問題の「のみ・必ず・だけ」など正解を推測しやすい絶対表現を除去
- 独自問題の選択肢を解説との対応を維持したまま毎回ランダム配置
- 主症状・随伴症状・悪化徴候を示す臨床観察カードとスマートフォン用症状通知
- 解説ごとの誤り報告フォーム（端末に控えを保存し、設定したメールへ送信）
- QUICK（10問）・STANDARD（20問）・SURVIVAL（30問）の3モード
- 疾患領域を指定した集中演習
- XP・レベル・問題別習熟度・実績解除・ブックマーク
- 結果画面の領域別パフォーマンス分析
- 誤答回数ではなく、病態の危険度（軽症・中等症・重症・生命危機）で決まる固定ダメージ
- PWA対応（GitHub Pagesではホーム画面へインストール可能、再訪時はオフライン起動に対応）

## 誤り報告の受信設定

`config.js` の `feedbackEmail` に受信用メールアドレスを設定します。現在は `recare.feedback@gmail.com` です。FormSubmitのAJAXエンドポイントへ直接送信するため、報告者のメールアプリは開きません。最初の報告時に受信先へ届く有効化メールの承認が必要です。控えはブラウザの `localStorage` にも保存します。
- PC／スマートフォン対応

## 出典と注意

問題文・正答は、厚生労働省「第115回看護師国家試験の問題および正答」をもとにゲーム用に加工して作成しています。

- 出典: https://www.mhlw.go.jp/seisakunitsuite/bunya/kenkou_iryou/iryou/topics/tp260424-03_04_05.html
- 解説、分類、誤答時の症状表現は本ゲーム独自であり、厚生労働省による公式解説ではありません。
- 学習補助用のプロトタイプです。診療・看護判断には使用できません。
- 公開前に医療有資格者による内容監修を推奨します。

## 問題の追加

`questions.js` の `QUESTION_BANK` に同じ形式のオブジェクトを追加します。画像・図表問題は権利確認と表示機能の整備が完了するまで収録しない方針です。

独自問題は `expanded-disease-pack.js`、`expanded-disease-pack-2.js`、`mega-disease-pack.js` に収録しています。画面上で「独自作成・疾患別演習」と表示し、公式過去問と区別しています。
